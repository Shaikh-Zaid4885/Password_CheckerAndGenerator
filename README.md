# Password_CheckerAndGenerator
A Python-based Password Strength Checker and Generator built with Tkinter. It analyzes password strength based on length, character diversity, and complexity, while providing a secure random password generator with copy and visibility options.

#How to Run
1. Clone this repository
2. Open the folder in terminal or VS Code
3. Run: password_checker.py
4. Make sure Python 3 is installed.
   ✅ The Tkinter window will open — check or generate passwords easily.
